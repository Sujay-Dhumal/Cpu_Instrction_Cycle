What the CPU does in each phase
LEARN
01
Fetch · Get the instruction

The Program Counter identifies the instruction address. The CPU fetches the instruction into the Instruction Register, then advances the PC.

02
Decode · Understand the instruction

The control unit interprets the opcode and identifies which registers or memory locations are needed.

03
Execute · Do the operation

The ALU performs arithmetic or the CPU moves data. Updated register and memory values appear in the register bank.
